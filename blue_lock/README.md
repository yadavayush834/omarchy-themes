# Blue Lock for Omarchy

An unofficial fan-made Omarchy theme inspired by *Blue Lock*: a midnight
striker-analysis room with electric cobalt flow states, cyan spatial-awareness
signals, crisp white scoreboard text, and controlled red-card alerts.

## Design direction

- Deep navy surfaces echo the Blue Lock training facility and uniform colors.
- Electric blue marks active players, selected controls, and focused windows.
- Cyan represents spatial awareness, live analysis, and connected systems.
- Pitch green is reserved for charging and healthy states.
- Red appears only for urgent, disconnected, recording, or critical states.

## Included

- A complete Omarchy color palette for generated terminal, editor, browser,
  btop, Hyprland, and application themes.
- Native Omarchy shell styling for the bar, launcher, menus, controls,
  notifications, lock screen, authentication, popups, and wallpaper picker.
- A calm custom Waybar with simple numbered workspaces, a centered clock,
  understated window titles, compact icon-based system status, and restrained
  blue interaction states.
- Three supplied 1920px Blue Lock wallpapers.
- Yaru blue dark icons.

## Install locally

Link or copy this directory to:

```text
~/.config/omarchy/themes/blue-lock
```

Then apply it:

```bash
omarchy theme set blue-lock
```

Cycle backgrounds with:

```bash
omarchy theme bg next
```
